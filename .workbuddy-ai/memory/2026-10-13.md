# 2026-10-13

## Kytia Habit — habit tracker Vue 3 + Firebase (dibangun dari nol)

**Tujuan:** website tracking daily habit dengan view mingguan & bulanan.

**Tech stack:** Vue 3 + Vite 6, Vue Router 4, Pinia, Firebase (Auth + Firestore).
Firebase di-load **lazy** (`src/firebase.js` → `loadFirebase()`) supaya bundle awal
tetap ~142 kB; tanpa env Firebase app jalan di **Demo Mode** (localStorage).

**Desain layout** (hasil riset habit tracker minimalis):
- View **mingguan** = weekly row layout (7 kolom, sel besar, nilai ditulis langsung)
- View **bulanan** = monthly grid / heatmap (habit × tanggal, sel compact berwarna)
- Keduanya pakai satu komponen `MatrixGrid.vue` dengan struktur matrix yang sama:
  16 baris dikelompokkan jadi 7 grup, tiap grup ada header + bar rata-rata.
- Klik sel mana pun → `DayEditor.vue` (slide-over panel).

**7 habit & 16 baris matrix:**
| grup | baris | tipe |
|---|---|---|
| salat | Subuh/Dzuhur/Ashar/Maghrib/Isya | status 4 warna (tepat=hijau, telat=kuning, sangat telat=oren, tidak=merah) |
| lari | km | angka, target 3 km |
| semedi | Wimhof (round), Meditasi (menit) | angka, target 3 round & 10 menit |
| kerja | Fase 1/2/3 | pomodoro, **min 3 per fase**, target total 9 |
| notoxic | Fase 1/2/3 | status 4 warna (bersih/sedikit/banyak/toxic) |
| jurnaling | pomodoro | angka, target 1 |
| belajar | pomodoro | angka, target 1 |

**Keputusan teknis penting:**
- Sumber kebenaran tunggal ada di `src/lib/constants.js` — nambah/ubah habit cukup di sini,
  matrix + editor + skor ikut menyesuaikan.
- Ambang warna heatmap angka (`ratioColor`): ≥0.8 hijau, ≥0.5 kuning, ≥0.25 oren, >0 merah.
  Salat/no-toxic TIDAK pakai ambang ini — warnanya langsung dari level yang dipilih user.
- Minggu mulai **Senin**; date key format `YYYY-MM-DD` (waktu lokal, bukan UTC).
- Firestore: `users/{uid}/days/{YYYY-MM-DD}`, query per bulan, cache `loadedMonths`.
- Streak dihitung dari 60 hari terakhir (di-load sekali saat mount), hari ini boleh kosong
  tanpa memutus streak.

**Catatan environment (penting untuk sesi berikutnya):**
- `npm install` **gagal** di postinstall esbuild dengan `EBUSY` saat spawnSync node.exe.
  Akibatnya `@esbuild/win32-x64` dan `@rollup/rollup-win32-x64-msvc` tidak terpasang.
  Fix: `npm install --no-save --ignore-scripts @esbuild/win32-x64@<versi> @rollup/rollup-win32-x64-msvc@<versi>`.
- Selalu jalankan build dengan `CODEBUDDY_SAFE_DELETE_ENABLED=0` prefix.
- Dev server: `vite --port 5173 --host 127.0.0.1`, jalankan dengan `run_in_background: true`.

**Verifikasi:** `vite build` sukses; 44 tes logika (struktur/tanggal/skor/statistik) lolos.
Tes dijalankan dengan cara bundle `src/lib/*` pakai esbuild ke ESM lalu run di Node
(module lib tidak import Vue, jadi bisa diuji langsung).

## Update 4 — persiapan deploy Cloudflare Pages

User mau publish ke Cloudflare Pages. Dari dokumentasi resmi Cloudflare
(developers.cloudflare.com/pages/configuration/build-configuration), preset **Vue** =
build `npm run build`, output `dist` — persis kebutuhan proyek ini. (Dropdown dashboard
juga punya **Vite**; untuk proyek ini nilainya identik. Catatan: tabel resmi hanya
mendaftar "React (Vite)", tidak ada entri "Vite" generik.)

File baru (Vite otomatis menyalin `public/` ke root `dist/`):
- `public/_redirects` → `/*    /index.html   200`. **Wajib** karena router pakai
  `createWebHistory()` — tanpa ini refresh di `/login` = 404 di Cloudflare.
- `public/_headers` → `/assets/*` immutable 1 tahun, `index.html` must-revalidate.

Catatan deploy penting:
- Vite **inline** `VITE_*` ke bundle saat build → env var harus diisi di
  Pages → Settings → Environment variables (Production **dan** Preview). Kalau lupa,
  app diam-diam jalan di Demo Mode (tidak error) — jebakan yang gampang terlewat.
- Setelah deploy, domain `*.pages.dev` harus ditambahkan ke Firebase Console →
  Authentication → Settings → **Authorized domains**, kalau tidak kena
  `auth/unauthorized-domain`.
- Repo git: remote `https://github.com/kyuraha/kytiahabit.git`, branch utama, commit
  awal `d2332f3 "startup"`. `.env` aman (tidak ter-track, sudah di .gitignore).
